\hypertarget{dir_772ead685b9d496e78573f3740fb4e67_autotoc_md174}{}\doxysubsection{\texorpdfstring{Voice Activity Detection (VAD)}{Voice Activity Detection (VAD)}}\label{dir_772ead685b9d496e78573f3740fb4e67_autotoc_md174}
Support for Voice Activity Detection (VAD) can be enabled using the {\ttfamily -\/-\/vad} argument to {\ttfamily whisper-\/cli}. In addition to this option a VAD model is also required.

\doxylink{requirements_The}{The} way this works is that first the audio samples are passed through the VAD model which will detect speech segments. Using this information, only the speech segments that are detected are extracted from the original audio input and passed to whisper for processing. This reduces the amount of audio data that needs to be processed by whisper and can significantly speed up the transcription process.

\doxylink{requirements_The}{The} following VAD models are currently supported:\+\hypertarget{dir_772ead685b9d496e78573f3740fb4e67_autotoc_md175}{}\doxysubsubsection{\texorpdfstring{Silero-\/\+VAD}{Silero-\/\+VAD}}\label{dir_772ead685b9d496e78573f3740fb4e67_autotoc_md175}

\begin{DoxyItemize}
\item --vad-\/threshold:\+ Threshold probability for speech detection. A probability for a speech segment/\+frame above this threshold will be considered as speech.
\item --vad-\/min-\/speech-\/duration-\/ms:\+ Minimum speech duration in milliseconds. Speech segments shorter than this value will be discarded to filter out brief noise or false positives.
\item --vad-\/min-\/silence-\/duration-\/ms:\+ Minimum silence duration in milliseconds. Silence periods must be at least this long to end a speech segment. Shorter silence periods will be ignored and included as part of the speech.
\item --vad-\/max-\/speech-\/duration-\/s:\+ Maximum speech duration in seconds. Speech segments longer than this will be automatically split into multiple segments at silence points exceeding 98ms to prevent excessively long segments.
\item --vad-\/speech-\/pad-\/ms:\+ Speech padding in milliseconds. Adds this amount of padding before and after each detected speech segment to avoid cutting off speech edges.
\item --vad-\/samples-\/overlap:\+ Amount of audio to extend from each speech segment into the next one, in seconds (e.\+g., 0.\+10 = 100ms overlap). This ensures speech isn\textquotesingle{}t cut off abruptly between segments when they\textquotesingle{}re concatenated together.
