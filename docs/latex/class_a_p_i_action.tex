\doxysubsection{Detailed Description}
\doxylink{class_action}{Action} that creates a Google Calendar event via the Calendar REST API. 

\begin{DoxyAuthor}{Author}
Meridith Shang 
\end{DoxyAuthor}
Inherits from \doxylink{class_action}{Action} and implements \doxylink{class_a_p_i_action_a926ae55195eb5e8b0bf8756e19227c90}{execute()} to POST the event to Google Calendar. OAuth 2.\+0 authentication is handled transparently:\+ the stored refresh token is exchanged for a short-\/lived access token on every call to \doxylink{class_a_p_i_action_a926ae55195eb5e8b0bf8756e19227c90}{execute()}.
