\doxysubsection{Detailed Description}
\doxylink{class_action}{Action} that finds and plays the first You\+Tube result for a given song. 

Uses the You\+Tube Data API v3 (when an API key is present in config.\+ini) to resolve the best matching video ID, then opens the resulting youtube.\+com/\+watch URL in the OS default browser.
