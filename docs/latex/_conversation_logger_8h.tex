\doxysubsection{Detailed Description}
Real-\/time JSON logger for command/\+response exchanges. 

Every exchange is appended to a JSON array immediately after it occurs, so the log file is always current — even if the program exits unexpectedly. \doxylink{requirements_The}{The} output file is a valid JSON array for the entire session.
