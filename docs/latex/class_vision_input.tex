\doxysubsection{Detailed Description}
Manages a Python subprocess for real-\/time hand gesture detection. 

This class spawns and communicates with a Python script (detect.\+py) that performs hand gesture recognition using the webcam. Gesture data is read line-\/by-\/line from the subprocess\textquotesingle{}s stdout, providing gesture names and normalized hand position coordinates. \doxylink{requirements_The}{The} subprocess is automatically terminated on destruction or when explicitly stopped.

Starts the gesture detection subprocess. 

Launches detect.\+py using the platform-\/specific Python interpreter from the virtual environment. If a subprocess is already running, it is stopped first. On mac\+OS/\+\+Linux, uses pgrep to obtain the process ID for later termination. On Windows, uses Power\+Shell to find the python process.
