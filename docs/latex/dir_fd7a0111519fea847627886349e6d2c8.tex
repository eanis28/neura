Inference of \href{https://github.com/openai/whisper}{\texttt{Open\+AI\textquotesingle{}s Whisper ASR model}} inside the browser

This example uses a Web\+Assembly (WASM) port of the \href{https://github.com/ggerganov/whisper.cpp}{\texttt{whisper.\+cpp}} implementation of the transformer to run the inference inside a web page. \doxylink{requirements_The}{The} audio data does not leave your computer -\/ it is processed locally on your machine. \doxylink{requirements_The}{The} performance is not great but you should be able to achieve x2 or x3 real-\/time for the {\ttfamily tiny} and {\ttfamily base} models on a modern CPU and browser (i.\+e. transcribe a 60 seconds audio in about \texorpdfstring{$\sim$}{\string~}20-\/30 seconds).

This WASM port utilizes \href{https://emcc.zcopy.site/docs/porting/simd/}{\texttt{WASM SIMD 128-\/bit intrinsics}} so you have to make sure that \href{https://webassembly.org/roadmap/}{\texttt{your browser supports them}}.

\doxylink{requirements_The}{The} example is capable of running all models up to size {\ttfamily small} inclusive. Beyond that, the memory requirements and performance are unsatisfactory. \doxylink{requirements_The}{The} implementation currently support only the {\ttfamily Greedy} sampling strategy. Both transcription and translation are supported.

Since the model data is quite big (74MB for the {\ttfamily tiny} model) you need to manually load the model into the web-\/page.

\doxylink{requirements_The}{The} example supports both loading audio from a file and recording audio from the microphone. \doxylink{requirements_The}{The} maximum length of the audio is limited to 120 seconds.\hypertarget{dir_fd7a0111519fea847627886349e6d2c8_autotoc_md128}{}\doxysubsection{\texorpdfstring{Live demo}{Live demo}}\label{dir_fd7a0111519fea847627886349e6d2c8_autotoc_md128}
