\begin{quote}
{\bfseries{Note:\+}} Install \href{https://k6.io/docs/get-started/installation/}{\texttt{k6}} before running the benchmark script. \end{quote}


You can benchmark the Whisper server using the provided bench.\+js script with \href{https://k6.io/}{\texttt{k6}}. This script sends concurrent multipart requests to the /\+inference endpoint and is fully configurable via environment variables.

{\bfseries{Example usage:\+}}


\begin{DoxyCode}{0}
\DoxyCodeLine{k6\ run\ bench.js\ \(\backslash\)}
\DoxyCodeLine{\ \ -\/-\/env\ FILE\_PATH=/absolute/path/to/samples/jfk.wav\ \(\backslash\)}
\DoxyCodeLine{\ \ -\/-\/env\ BASE\_URL=http://127.0.0.1:8080\ \(\backslash\)}
\DoxyCodeLine{\ \ -\/-\/env\ ENDPOINT=/inference\ \(\backslash\)}
\DoxyCodeLine{\ \ -\/-\/env\ CONCURRENCY=4\ \(\backslash\)}
\DoxyCodeLine{\ \ -\/-\/env\ TEMPERATURE=0.0\ \(\backslash\)}
\DoxyCodeLine{\ \ -\/-\/env\ TEMPERATURE\_INC=0.2\ \(\backslash\)}
\DoxyCodeLine{\ \ -\/-\/env\ RESPONSE\_FORMAT=json}

\end{DoxyCode}


{\bfseries{Environment variables:\+}}
\begin{DoxyItemize}
\item {\ttfamily FILE\+\_\+\+PATH}:\+ Path to the audio file to send (must be absolute or relative to the k6 working directory)
\item {\ttfamily BASE\+\_\+\+URL}:\+ Server base URL (default:\+ {\ttfamily \href{http://127.0.0.1:8080}{\texttt{http:\+/\+/\+127.\+0.\+0.\+1:\+8080}}})
\item {\ttfamily ENDPOINT}:\+ API endpoint (default:\+ {\ttfamily /\+inference})
\item {\ttfamily CONCURRENCY}:\+ Number of concurrent requests (default:\+ 4)
\item {\ttfamily TEMPERATURE}:\+ Decoding temperature (default:\+ 0.\+0)
\item {\ttfamily TEMPERATURE\+\_\+\+INC}:\+ Temperature increment (default:\+ 0.\+2)
\item {\ttfamily RESPONSE\+\_\+\+FORMAT}:\+ Response format (default:\+ {\ttfamily json})
\end{DoxyItemize}

{\bfseries{Note:\+}}
\begin{DoxyItemize}
\item \doxylink{requirements_The}{The} server must be running and accessible at the specified {\ttfamily BASE\+\_\+\+URL} and {\ttfamily ENDPOINT}.
\item \doxylink{requirements_The}{The} script is located in the same directory as this README:\+ {\ttfamily bench.\+js}. 
\end{DoxyItemize}
