\doxysubsection{Detailed Description}
A sample Android app using \+[whisper.\+cpp]\+(\href{https://github.com/ggerganov/whisper.cpp/}{\texttt{https:\+/\+/\+github.\+com/\+ggerganov/\+whisper.\+cpp/\+}}) to do voice-\/to-\/text transcriptions.

To use:\+


\begin{DoxyEnumerate}
\item Select a model from the \href{https://github.com/ggerganov/whisper.cpp/tree/master/models}{\texttt{whisper.\+cpp repository}}.\+[\texorpdfstring{$^\wedge$}{\string^}1]\+
\item Copy the model to the "{}app/\+src/\+main/\+assets/\+models"{} folder.
\item Select a sample audio file (for example, \href{https://github.com/ggerganov/whisper.cpp/raw/master/samples/jfk.wav}{\texttt{jfk.\+wav}}).
\item Copy the sample to the "{}app/\+src/\+main/\+assets/\+samples"{} folder.
\item Select the "{}release"{} active build variant, and use Android Studio to run and deploy to your device. \+[\texorpdfstring{$^\wedge$}{\string^}1]\+:\+ I recommend the tiny or base models for running on an Android device.
\end{DoxyEnumerate}

(PS:\+ Do not move this android project folder individually to other folders, because this android project folder depends on the files of the whole project.)
