Opens the Neura Quick Reference window. 

Launches a separate, non-\/blocking window that displays a structured overview of all assistant capabilities, including:\+


\begin{DoxyItemize}
\item Voice commands (e.\+g., time, screenshot, volume, brightness)
\item System controls (tabs, windows, recording, reading text)
\item Gesture interactions (cursor movement, drag, cancel, yes/\+no)
\item Advanced features (weather, media playback, calendar events, search)
\item General usage tips and shortcuts
\end{DoxyItemize}

This window runs independently of the main UI and does not interrupt or close the primary assistant interface.

Opens the Neura Quick Reference window.

Creates a scrollable SFML window displaying categorized voice commands and gesture controls for Neura. \doxylink{requirements_The}{The} content is rendered as a vertical list with section headers and command descriptions.

Features:\+
\begin{DoxyItemize}
\item Platform-\/specific font loading
\item Scrollable content using mouse wheel
\item Automatic layout generation from item list
\end{DoxyItemize}

\begin{DoxyNote}{Note}
\doxylink{requirements_The}{The} window runs its own event loop and blocks until closed.
