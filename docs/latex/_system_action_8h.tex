\doxysubsection{Detailed Description}
OS-\/level media playback control via simulated media keys. 

Provides a cross-\/platform mechanism for pausing, playing, or toggling media playback by dispatching the appropriate OS-\/level command for the current platform All platform branching is contained within send\+Media\+Key() to keep the rest of the class portable. \begin{DoxyAuthor}{Author}
