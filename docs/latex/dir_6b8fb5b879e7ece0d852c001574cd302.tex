This example uses the whisper.\+xcframework which needs to be built first using the following command:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{./build-\/xcframework.sh}

\end{DoxyCode}


A model is also required to be downloaded and can be done using the following command:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{./models/download-\/ggml-\/model.sh\ base.en}

\end{DoxyCode}


If you don\textquotesingle{}t want to convert a Core ML model, you can skip this step by creating dummy model:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{mkdir\ models/ggml-\/base.en-\/encoder.mlmodelc}

\end{DoxyCode}

\item Follow all the steps in the {\ttfamily Usage} section, including adding the ggml model file. ~\newline
 \doxylink{requirements_The}{The} ggml model file is required as the Core ML model is only used for the encoder. \doxylink{requirements_The}{The} decoder which is in the ggml model is still required.
