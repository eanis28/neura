\doxysubsection{Detailed Description}
Thread-\/safe container for passing responses between threads. 

This structure is used to safely share text responses (such as voice command outputs) between worker threads (e.\+g., voice listener) and the main UI thread.

It uses a mutex to ensure synchronized access and a flag to indicate when new data is available.
