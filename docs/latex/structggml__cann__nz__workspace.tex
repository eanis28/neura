\doxysubsection{Detailed Description}
Workspace for caching NZ buffers per device. 

This struct manages a device buffer used in NZ computations. It supports allocation, reallocation, and clearing of cached memory. \doxylink{requirements_The}{The} struct is designed to be used with a global array, one per device.
