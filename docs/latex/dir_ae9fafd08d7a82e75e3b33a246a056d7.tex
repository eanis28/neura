\hypertarget{dir_ae9fafd08d7a82e75e3b33a246a056d7_autotoc_md21}{}\doxysubsection{\texorpdfstring{Building \& Testing}{Building \& Testing}}\label{dir_ae9fafd08d7a82e75e3b33a246a056d7_autotoc_md21}
In order to build, you need to have the Go compiler installed. You can get it from \href{https://golang.org/dl/}{\texttt{here}}. Run the tests with:\+


\begin{DoxyCode}{0}
\DoxyCodeLine{git\ clone\ https://github.com/ggml-\/org/whisper.cpp.git}
\DoxyCodeLine{cd\ whisper.cpp/bindings/go}
\DoxyCodeLine{make\ test}

\end{DoxyCode}


This will compile a static {\ttfamily libwhisper.\+a} in a {\ttfamily build} folder, download a model file, then run the tests. To build the examples:\+


\begin{DoxyCode}{0}
\DoxyCodeLine{make\ examples}

\end{DoxyCode}


To build using cuda support add {\ttfamily GGML\+\_\+\+CUDA=1}:\+


\begin{DoxyCode}{0}
\DoxyCodeLine{GGML\_CUDA=1\ make\ examples}

\end{DoxyCode}


\doxylink{requirements_The}{The} examples are placed in the {\ttfamily build} directory. Once built, you can download all the models with the following command:\+


\begin{DoxyCode}{0}
\DoxyCodeLine{./build/go-\/model-\/download\ -\/out\ models}

\end{DoxyCode}


And you can then test a model against samples with the following command:\+


\begin{DoxyCode}{0}
\DoxyCodeLine{./build/go-\/whisper\ -\/model\ models/ggml-\/tiny.en.bin\ samples/jfk.wav}

\end{DoxyCode}
\hypertarget{dir_ae9fafd08d7a82e75e3b33a246a056d7_autotoc_md22}{}\doxysubsection{\texorpdfstring{Using the bindings}{Using the bindings}}\label{dir_ae9fafd08d7a82e75e3b33a246a056d7_autotoc_md22}
To use the bindings in your own software,


\begin{DoxyEnumerate}
\item Import {\ttfamily github.\+com/\+ggerganov/\+whisper.cpp/\+bindings/\+go/\+pkg/\+whisper} (or {\ttfamily github.\+com/\+ggerganov/\+whisper.cpp/\+bindings/\+go} into your package;
\item Compile {\ttfamily libwhisper.\+a} (you can use {\ttfamily make whisper} in the {\ttfamily bindings/\+go} directory);
\item Link your go binary against whisper by setting the environment variables {\ttfamily C\+\_\+\+INCLUDE\+\_\+\+PATH} and {\ttfamily LIBRARY\+\_\+\+PATH} to point to the {\ttfamily \doxylink{whisper_8h_source}{whisper.\+h}} file directory and {\ttfamily libwhisper.\+a} file directory respectively.
\end{DoxyEnumerate}

Look at the {\ttfamily Makefile} in the {\ttfamily bindings/\+go} directory for an example.
