chessboard.\+js is a Java\+Script chessboard component with a flexible "{}just a board"{} API that

chessboard.\+js is a standalone Java\+Script Chess Board. It is designed to be "{}just a board"{} and expose a powerful API so that it can be used in different ways. Here\textquotesingle{}s a non-\/exhaustive list of things you can do with chessboard.\+js:\+


\begin{DoxyItemize}
\item Use chessboard.\+js to show game positions alongside your expert commentary.
\item Use chessboard.\+js to have a tactics website where users have to guess the best move.
\item Integrate chessboard.\+js and \href{https://github.com/jhlywa/chess.js}{\texttt{chess.\+js}} with a PGN database and allow people to search and playback games (see \href{http://chessboardjs.com/examples\#5000}{\texttt{Example 5000}})
\item Build a chess server and have users play their games out using the chessboard.\+js board.
\end{DoxyItemize}

chessboard.\+js is flexible enough to handle any of these situations with relative ease.\hypertarget{dir_19ef4fd288cc90b1dde2c8e188f87f19_autotoc_md111}{}\doxysubsection{\texorpdfstring{What can chessboard.\+js {\bfseries{not}} do?}{What can chessboard.\+js {\bfseries{not}} do?}}\label{dir_19ef4fd288cc90b1dde2c8e188f87f19_autotoc_md111}
\doxylink{requirements_The}{The} scope of chessboard.\+js is limited to "{}just a board."{} This is intentional and makes chessboard.\+js flexible for handling a multitude of chess-\/related problems.

This is a common source of confusion for new users. \+[remove?]\+

Specifically, chessboard.\+js does not understand anything about how the game of chess is played:\+ how a knight moves, who\textquotesingle{}s turn is it, is White in check?, etc.

Fortunately, the powerful \href{https://github.com/jhlywa/chess.js}{\texttt{chess.\+js}} library deals with exactly this sort of problem domain and plays nicely with chessboard.\+js\textquotesingle{}s flexible API. Some examples of chessboard.\+js combined with chess.\+js:\+ 5000, 5001, 5002

Please see the powerful \href{https://github.com/jhlywa/chess.js}{\texttt{chess.\+js}} library for an API to deal with these sorts of questions.

This logic is distinct from the logic of the board. Please see the powerful \href{https://github.com/jhlywa/chess.js}{\texttt{chess.\+js}} library for this aspect of your application.

Here is a list of things that chessboard.\+js is {\bfseries{not}}:\+


\begin{DoxyItemize}
\item A chess engine
\item A legal move validator
\item A PGN parser
\end{DoxyItemize}
