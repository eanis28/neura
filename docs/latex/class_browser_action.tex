\doxysubsection{Detailed Description}
Opens the first You\+Tube video matching a song title and artist. 

Inherits HTTP helpers and configuration access from \doxylink{class_action}{Action}. On \doxylink{class_browser_action_adafe724cef6bfb133d9216d2814336e1}{execute()}, the action:\+
\begin{DoxyItemize}
\item Calls \doxylink{class_browser_action_a3037f0b4659a03217bd16ee5d512fd17}{fetch\+First\+Video\+Id()} to query the You\+Tube Data API v3.
\item Falls back to \doxylink{class_browser_action_aa6eb6194f96df2360ec5004eeaf64f03}{build\+Fallback\+Search\+Url()} if the API call fails or no API key is configured.
\item Passes the resolved URL to \doxylink{class_browser_action_acfb0667328640cf197dc4c5f71f59832}{open\+In\+Browser()}, which delegates to the platform\textquotesingle{}s default browser launcher ({\ttfamily xdg-\/open} on Linux, open on mac\+OS, start on Windows).
\end{DoxyItemize}
