\doxysubsection{Detailed Description}
Application configuration:\+ API credentials, feature permissions, and runtime settings. 

Google Calendar authentication uses OAuth 2.\+0 with a long-\/lived refresh token. \doxylink{requirements_The}{The} refresh token is obtained once via the OAuth flow and stored permanently in config.\+ini. On every run, the assistant exchanges it for a fresh short-\/lived access token automatically — no user interaction is required after initial setup. \begin{DoxyAuthor}{Author}
