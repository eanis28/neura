This is a naive example of performing real-\/time inference on audio from your microphone. \doxylink{requirements_The}{The} {\ttfamily whisper-\/stream} tool samples the audio every half a second and runs the transcription continously. Setting the {\ttfamily -\/-\/step} argument to {\ttfamily 0} enables the sliding window mode:\+

\DoxyCodeLine{./build/bin/whisper-\/stream\ -\/m\ ./models/ggml-\/base.en.bin\ -\/t\ 6\ -\/-\/step\ 0\ -\/-\/length\ 30000\ -\/vth\ 0.6}

\end{DoxyCode}


In this mode, the tool will transcribe only after some speech activity is detected. A very basic VAD detector is used, but in theory a more sophisticated approach can be added. \doxylink{requirements_The}{The} {\ttfamily -\/vth} argument determines the VAD threshold -\/ higher values will make it detect silence more often. It\textquotesingle{}s best to tune it to the specific use case, but a value around {\ttfamily 0.\+6} should be OK in general. When silence is detected, it will transcribe the last {\ttfamily -\/-\/length} milliseconds of audio and output a transcription block that is suitable for parsing.\hypertarget{dir_63ce1c9e53f3f204ebd97830a8594ec5_autotoc_md86}{}\doxysubsection{\texorpdfstring{Building}{Building}}\label{dir_63ce1c9e53f3f204ebd97830a8594ec5_autotoc_md86}
