\doxysubsection{Detailed Description}
Stores all user-\/configurable application settings. 

Settings are persisted to and loaded from a plain-\/text .ini file using simple key=value format. \doxylink{requirements_The}{The} global instance g\+\_\+settings is loaded once at startup and written back when the user saves changes in the settings UI.
