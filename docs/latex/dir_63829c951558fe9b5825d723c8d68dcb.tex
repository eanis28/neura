Speech-\/to-\/text in Neovim

\doxylink{requirements_The}{The} transcription is performed on the CPU and no data leaves your computer. Works best on Apple Silicon devices.

\href{https://user-images.githubusercontent.com/1991296/198382564-784e9663-2037-4d04-99b8-f39136929b7e.mp4}{\texttt{https:\+/\+/\+user-\/images.\+githubusercontent.\+com/\+1991296/\+198382564-\/784e9663-\/2037-\/4d04-\/99b8-\/f39136929b7e.\+mp4}}\hypertarget{dir_63829c951558fe9b5825d723c8d68dcb_autotoc_md116}{}\doxysubsection{\texorpdfstring{Usage}{Usage}}\label{dir_63829c951558fe9b5825d723c8d68dcb_autotoc_md116}

\begin{DoxyItemize}
\item Simply press {\ttfamily Ctrl-\/G} in {\ttfamily INSERT}, {\ttfamily VISUAL} or {\ttfamily NORMAL} mode and say something
\item When you are done -\/ press {\ttfamily Ctrl-\/C} to end the transcription and insert the transcribed text under the cursor
\end{DoxyItemize}\hypertarget{dir_63829c951558fe9b5825d723c8d68dcb_autotoc_md117}{}\doxysubsection{\texorpdfstring{Installation}{Installation}}\label{dir_63829c951558fe9b5825d723c8d68dcb_autotoc_md117}
{\itshape Note:\+ this is a bit tedious and hacky atm, but I hope it will be improved with time}


\begin{DoxyItemize}
\item Clone this repo and build the {\ttfamily stream} tool:\+


\begin{DoxyCode}{0}
\DoxyCodeLine{git\ clone\ https://github.com/ggerganov/whisper.cpp}
\DoxyCodeLine{cd\ whisper.cpp}
\DoxyCodeLine{make\ stream}

\end{DoxyCode}

\item Download the {\ttfamily base.\+en} Whisper model (140 MB):\+


\begin{DoxyCode}{0}
\DoxyCodeLine{./models/download-\/ggml-\/model.sh\ base.en}

\end{DoxyCode}

\item Place the \href{whisper.nvim}{\texttt{whisper.\+nvim}} script somewhere in your PATH and give it execute permissions:\+


\begin{DoxyCode}{0}
\DoxyCodeLine{cp\ examples/whisper.nvim/whisper.nvim\ \string~/bin/}
\DoxyCodeLine{chmod\ u+x\ \string~/bin/whisper.nvim}

\end{DoxyCode}

\item Fine-\/tune the script to your preference and machine parameters:\+


\begin{DoxyCode}{0}
\DoxyCodeLine{./stream\ -\/t\ 8\ -\/m\ models/ggml-\/base.en.bin\ -\/-\/step\ 350\ -\/-\/length\ 10000\ -\/f\ /tmp/whisper.nvim\ 2>\ /dev/null}

\end{DoxyCode}


On slower machines, try to increase the {\ttfamily step} parameter.
\item \doxylink{struct_add}{Add} the following shortcuts to your {\ttfamily \texorpdfstring{$\sim$}{\string~}/\+.config/\+nvim/\+init.\+vim}:\+

\end{DoxyCode}


Explanation:\+ pressing {\ttfamily Ctrl-\/G} runs the \href{whisper.nvim}{\texttt{whisper.\+nvim}} script which in turn calls the {\ttfamily stream} binary to transcribe your speech through the microphone. \doxylink{requirements_The}{The} results from the transcription are continuously dumped into {\ttfamily /\+tmp/\+whisper.nvim}. After you kill the program with {\ttfamily Ctrl-\/C}, the vim command grabs the last line from the {\ttfamily /\+tmp/\+whisper.nvim} file and puts it under the cursor.

Probably there is a much more intelligent way to achieve all this, but this is what I could hack in an hour. Any suggestions how to improve this are welcome.
\end{DoxyItemize}
