\doxysubsection{Detailed Description}
\hypertarget{dir_8e504aced5fcae1a8b85685333c56618_autotoc_md64}{}\doxysubsection{\texorpdfstring{whisper.\+cpp/\+examples/\+bench}{whisper.\+cpp/\+examples/\+bench}}\label{dir_8e504aced5fcae1a8b85685333c56618_autotoc_md64}
A very basic tool for benchmarking the inference performance on your device. \doxylink{requirements_The}{The} tool simply runs the Encoder part of the transformer on some random audio data and records the execution time. This way we can have an objective comparison of the performance of the model for various setups.

Benchmark results are tracked in the following Github issue:\+ \href{https://github.com/ggml-org/whisper.cpp/issues/89}{\texttt{https:\+/\+/\+github.\+com/\+ggml-\/org/\+whisper.\+cpp/\+issues/\+89}}
