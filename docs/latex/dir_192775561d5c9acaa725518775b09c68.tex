\hypertarget{dir_192775561d5c9acaa725518775b09c68_autotoc_md49}{}\doxysubsection{\texorpdfstring{CI}{CI}}\label{dir_192775561d5c9acaa725518775b09c68_autotoc_md49}
In addition to \href{https://github.com/ggerganov/whisper.cpp/actions}{\texttt{Github Actions}} {\ttfamily whisper.\+cpp} uses a custom CI framework:\+

\href{https://github.com/ggml-org/ci}{\texttt{https:\+/\+/\+github.\+com/\+ggml-\/org/\+ci}}

It monitors the {\ttfamily master} branch for new commits and runs the \href{https://github.com/ggerganov/whisper.cpp/blob/master/ci/run.sh}{\texttt{ci/\+run.\+sh}} script on dedicated cloud instances. This allows us to execute heavier workloads compared to just using Github Actions. Also with time, the cloud instances will be scaled to cover various hardware architectures, including GPU and Apple Silicon instances.

Collaborators can optionally trigger the CI run by adding the {\ttfamily ggml-\/ci} keyword to their commit message. Only the branches of this repo are monitored for this keyword.

It is a good practice, before publishing changes to execute the full CI locally on your machine:\+


\begin{DoxyCode}{0}
\DoxyCodeLine{mkdir\ tmp}
\DoxyCodeLine{}
\DoxyCodeLine{\#\ CPU-\/only\ build}
\DoxyCodeLine{bash\ ./ci/run.sh\ ./tmp/results\ ./tmp/mnt}
\DoxyCodeLine{}
\DoxyCodeLine{\#\ with\ CUDA\ support}
\DoxyCodeLine{GG\_BUILD\_CUDA=1\ bash\ ./ci/run.sh\ ./tmp/results\ ./tmp/mnt}

\end{DoxyCode}
