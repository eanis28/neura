\doxysubsection{Detailed Description}
Tracks which optional features the user has granted consent for. 

\begin{DoxyAuthor}{Author}
Meridith Shang 
\end{DoxyAuthor}
Each flag guards a capability that may have privacy or cost implications. Flags default to false (deny-\/by-\/default). Use \doxylink{class_permissions_ab2358a501c651dc9bcaa6c41ab06e904}{has\+Permission()} to query and \doxylink{class_permissions_af1de5079834ea2198f81f444cf050f7c}{request\+Permission()} to prompt the user at runtime.
