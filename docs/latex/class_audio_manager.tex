\doxysubsection{Detailed Description}
Manages microphone audio input using Port\+Audio. 

This class wraps the lifecycle of a Port\+Audio input stream. It is responsible for initializing the selected microphone, starting the input stream, and stopping and cleaning up audio resources when finished.
