\doxysubsection{Detailed Description}
Adds an event to Google Calendar (with optional recurrence). 

Auth:\+ OAuth 2.\+0 with refresh token stored in config.\+ini. \doxylink{requirements_The}{The} assistant automatically exchanges the refresh token for a fresh access token on every run — no manual steps after initial setup (unless refresh token expires). \begin{DoxyAuthor}{Author}
