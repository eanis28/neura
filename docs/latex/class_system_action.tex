\doxysubsection{Detailed Description}
\doxylink{class_action}{Action} that controls OS-\/level media playback. 

\begin{DoxyAuthor}{Author}
Meridith Shang
\end{DoxyAuthor}


Inherits from \doxylink{class_action}{Action} and implements \doxylink{class_system_action_af99d42d8f8416f5f454a7594c875944c}{execute()} by calling the platform appropriate shell command that simulates a media key press. \doxylink{requirements_The}{The} active media player is detected at execution time and logged for diagnostics.
