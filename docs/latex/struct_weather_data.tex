\doxysubsection{Detailed Description}
Holds the weather data returned by a successful \doxylink{class_weather_action_a314ad36554b6a8b571374e7b4305aa66}{Weather\+Action::\+execute()} call. 

Populated by \doxylink{class_weather_action_a1be02eed81d251de4991190802a4d616}{Weather\+Action::\+parse\+Response()} and retrievable via \doxylink{class_weather_action_a6f230a93f12322a2aaf9df48de4fc431}{Weather\+Action::\+get\+Result()}. Temperature is provided in both Celsius and Fahrenheit for convenience; all other measurements use SI-\/adjacent units as noted per field. \begin{DoxyAuthor}{Author}
