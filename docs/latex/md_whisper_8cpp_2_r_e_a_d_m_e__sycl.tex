SYCL is a higher-\/level programming model to improve programming productivity on various hardware accelerators—such as CPUs, GPUs, and FPGAs. It is a single-\/source embedded domain-\/specific language based on pure C++17.

one\+API is a specification that is open and standards-\/based, supporting multiple architecture types including but not limited to GPU, CPU, and FPGA. \doxylink{requirements_The}{The} spec has both direct programming and API-\/based programming paradigms.

Intel uses the SYCL as direct programming language to support CPU, GPUs and FPGAs.

To avoid re-\/inventing the wheel, this code refers other code paths in llama.\+cpp (like Open\+BLAS, cu\+BLAS, CLBlast). We use a open-\/source tool \href{https://github.com/oneapi-src/SYCLomatic}{\texttt{SYCLomatic}} (Commercial release \href{https://www.intel.com/content/www/us/en/developer/tools/oneapi/dpc-compatibility-tool.html}{\texttt{Intel® DPC++ Compatibility Tool}}) migrate to SYCL.

\doxylink{requirements_The}{The} whisper.\+cpp for SYCL is used to support Intel GPUs.

For Intel CPU, recommend to use whisper.\+cpp for X86 (Intel MKL build).\hypertarget{md_whisper_8cpp_2_r_e_a_d_m_e__sycl_autotoc_md181}{}\doxysection{\texorpdfstring{OS}{OS}}\label{md_whisper_8cpp_2_r_e_a_d_m_e__sycl_autotoc_md181}

\begin{DoxyItemize}
\item Error:\+ {\ttfamily error while loading shared libraries:\+ libsycl.\+so.\+7:\+ cannot open shared object file:\+ No such file or directory}.

Miss to enable one\+API running environment.

Install one\+API base toolkit and enable it by:\+ {\ttfamily source /\+opt/\+intel/\+oneapi/\+setvars.sh}.
\item Hang during startup

llama.\+cpp use mmap as default way to read model file and copy to GPU. In some system, memcpy will be abnormal and block.

Solution:\+ add {\bfseries{--no-\/mmap}}.
