Models are multilingual unless the model name includes {\ttfamily .en}. Models ending in {\ttfamily -\/q5\+\_\+0} are \href{../README.md\#quantization}{\texttt{quantized}}. Models ending in {\ttfamily -\/tdrz} support local diarization (marking of speaker turns) using \href{https://github.com/akashmjn/tinydiarize}{\texttt{tinydiarize}}. More information about models is available \href{https://github.com/openai/whisper\#available-models-and-languages}{\texttt{upstream (openai/\+whisper)}}. \doxylink{requirements_The}{The} list above is a subset of the models supported by the \href{download-ggml-model.sh}{\texttt{download-\/ggml-\/model.\+sh}} script, but many more are available at \href{https://huggingface.co/ggerganov/whisper.cpp/tree/main}{\texttt{https:\+/\+/\+huggingface.\+co/\+ggerganov/\+whisper.\+cpp/\+tree/\+main}} and elsewhere.\hypertarget{dir_ed1912900bdd2dba357d4b741115b76b_autotoc_md135}{}\doxysubsection{\texorpdfstring{Model files for testing purposes}{Model files for testing purposes}}\label{dir_ed1912900bdd2dba357d4b741115b76b_autotoc_md135}
\doxylink{requirements_The}{The} model files prefixed with {\ttfamily for-\/tests-\/} are empty (i.\+e. do not contain any weights) and are used by the CI for testing purposes. They are directly included in this repository for convenience and the Github Actions CI uses them to run various sanitizer tests.\hypertarget{dir_ed1912900bdd2dba357d4b741115b76b_autotoc_md136}{}\doxysubsection{\texorpdfstring{Fine-\/tuned models}{Fine-\/tuned models}}\label{dir_ed1912900bdd2dba357d4b741115b76b_autotoc_md136}
There are community efforts for creating fine-\/tuned Whisper models using extra training data. For example, this \href{https://huggingface.co/blog/fine-tune-whisper}{\texttt{blog post}} describes a method for fine-\/tuning using Hugging Face (HF) Transformer implementation of Whisper. \doxylink{requirements_The}{The} produced models are in slightly different format compared to the original Open\+AI format. To read the HF models you can use the \href{convert-h5-to-ggml.py}{\texttt{convert-\/h5-\/to-\/ggml.\+py}} script like this:\+


\begin{DoxyCode}{0}
\DoxyCodeLine{git\ clone\ https://github.com/openai/whisper}
\DoxyCodeLine{git\ clone\ https://github.com/ggml-\/org/whisper.cpp}
\DoxyCodeLine{}
\DoxyCodeLine{\#\ clone\ HF\ fine-\/tuned\ model\ (this\ is\ just\ an\ example)}
\DoxyCodeLine{git\ clone\ https://huggingface.co/openai/whisper-\/medium}
\DoxyCodeLine{}
\DoxyCodeLine{\#\ convert\ the\ model\ to\ ggml}
\DoxyCodeLine{python3\ ./whisper.cpp/models/convert-\/h5-\/to-\/ggml.py\ ./whisper-\/medium/\ ./whisper\ .}

\end{DoxyCode}
