\doxysubsection{Detailed Description}
Holds all third-\/party API credentials and base URLs. 

\begin{DoxyAuthor}{Author}
Meridith Shang 
\end{DoxyAuthor}
Fields are populated by \doxylink{class_configuration_adf2992468f43f18aa8acb7b4b9c9cf98}{Configuration::\+load()} from config.\+ini. Base URL fields have sensible defaults and should only be changed when routing traffic through a proxy or a mock server during testing.

std::\+string APISettings::\+google\+Refresh\+Token}



Long-\/lived OAuth 2.\+0 refresh token used to obtain access tokens. 

Acquired once via the interactive OAuth consent flow and written to config.\+ini. It does not expire unless manually revoked at {\itshape myaccount.\+google.\+com/\+permissions}. \doxylink{requirements_The}{The} assistant exchanges it automatically for a fresh access token on every run.

\begin{DoxyWarning}{Warning}
Store securely — this token grants ongoing access to the user\textquotesingle{}s Google account within the approved scopes. 
\end{DoxyWarning}
