\doxysubsection{Detailed Description}
Shared buffer for microphone audio samples. 

This structure stores audio samples captured from Port\+Audio and provides a mutex to protect access when the buffer is shared between threads.

\doxylink{requirements_The}{The} audio input thread writes samples into this buffer, while the speech recognition component reads from it.
