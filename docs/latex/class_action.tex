\doxysubsection{Detailed Description}
Abstract base class for all executable actions. 

Holds a reference to the shared \doxylink{class_configuration}{Configuration} object and exposes synchronous HTTP helpers (backed by libcurl) plus RFC-\/3986 percent-\/encoding. Subclasses must override \doxylink{class_action_a018c91fe89cff73911c5862df0cd8f63}{execute()} and \doxylink{class_action_a564b8be4c69e16668ba4f41ec7dd6cbf}{describe()}; everything else is inherited. \begin{DoxyAuthor}{Author}
Meridith Shang 
\end{DoxyAuthor}
