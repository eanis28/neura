\doxysubsection{Detailed Description}
Provides platform-\/agnostic mouse and keyboard control via system APIs. 

This class encapsulates platform-\/specific mouse movement, clicking, dragging, and keyboard input functionality. It uses Core Graphics on mac\+OS, Send\+Input on Windows, and XTest on Linux to simulate user input events. Screen dimensions are automatically detected on construction for coordinate mapping.
