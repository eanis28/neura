\doxysubsection{Detailed Description}
Top-\/level configuration object; owns \doxylink{class_a_p_i_settings}{APISettings} and \doxylink{class_permissions}{Permissions}. 

\begin{DoxyAuthor}{Author}
Meridith Shang 
\end{DoxyAuthor}
Reads from and writes to an INI-\/style file (default:\+ config.\+ini). Construct with the path to the config file, then call \doxylink{class_configuration_adf2992468f43f18aa8acb7b4b9c9cf98}{load()} before accessing any settings.
