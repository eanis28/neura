Displays the application landing page with navigation options. 

Creates and runs a modal window showing the Neura landing screen with buttons for Start, Tutorial, and Settings. \doxylink{requirements_The}{The} window is centered on screen at half the desktop resolution. User can navigate to different parts of the application or close to exit.

\begin{DoxyReturn}{Returns}
true if user clicked Start or Tutorial (proceed to main app), false if user closed the window or pressed Escape (exit app) 
\end{DoxyReturn}
