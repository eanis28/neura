\doxysubsection{Detailed Description}
Fetches and exposes current weather for a given or resolved location. 

\begin{DoxyAuthor}{Author}
Meridith Shang 
\end{DoxyAuthor}
Inherits HTTP helpers from \doxylink{class_action}{Action}. On \doxylink{class_weather_action_a314ad36554b6a8b571374e7b4305aa66}{execute()}, the action:\+
\begin{DoxyItemize}
\item Resolves the target location via \doxylink{class_weather_action_a299e67e6357ac92a207842b82b5013e2}{resolve\+Location()} if none was provided at construction.
\item Builds and issues an Open\+Weather\+Map Current Weather API request using \doxylink{class_action_a31a34834f233fc45a14b944d48c1971d}{http\+Get()}.
\item Parses the JSON response body into a \doxylink{struct_weather_data}{Weather\+Data} struct via \doxylink{class_weather_action_a1be02eed81d251de4991190802a4d616}{parse\+Response()} and stores it as last\+Result. 
\end{DoxyItemize}
