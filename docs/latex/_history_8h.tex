\doxysubsection{Detailed Description}
Terminal UI page that displays the full conversation history. 

Reads all entries from conversation.\+json (written by \doxylink{class_conversation_logger}{Conversation\+Logger}) and renders them as a scrollable, paginated list in the terminal. \doxylink{requirements_The}{The} user can navigate back to the main menu or close the window entirely. \begin{DoxyAuthor}{Author}
Meridith Shang 
\end{DoxyAuthor}

Reads from conversation.\+json and displays all logged command/\+response exchanges in reverse-\/chronological or sequential order. Blocks until the user chooses to navigate away.

true if the user navigated back to the main menu; false if the user closed the window or an unrecoverable read error occurred.
