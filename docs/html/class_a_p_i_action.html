Detailed Description

Action that creates a Google Calendar event via the Calendar REST API.

Author
Meridith Shang

Inherits from Action and implements execute() to POST the event to Google Calendar. OAuth 2.0 authentication is handled transparently: the stored refresh token is exchanged for a short-lived access token on every call to execute().
