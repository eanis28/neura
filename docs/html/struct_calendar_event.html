Detailed Description

Plain data structure describing a Google Calendar event.

Author
Meridith Shang

All date/time strings must be ISO 8601 combined date-time format (YYYY-MM-DDTHH:MM:SS). The timeZone field must be a valid IANA time zone identifier (e.g. "America/Toronto").
