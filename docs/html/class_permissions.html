Detailed Description

Tracks which optional features the user has granted consent for.

Author
Meridith Shang

Each flag guards a capability that may have privacy or cost implications. Flags default to false (deny-by-default). Use hasPermission() to query and requestPermission() to prompt the user at runtime.
