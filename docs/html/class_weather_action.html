Detailed Description

Fetches and exposes current weather for a given or resolved location.

Author
Meridith Shang

Inherits HTTP helpers from Action. On execute(), the action:

  • Resolves the target location via resolveLocation() if none was provided at construction.
  • Builds and issues an OpenWeatherMap Current Weather API request using httpGet().
  • Parses the JSON response body into a WeatherData struct via parseResponse() and stores it as lastResult.
