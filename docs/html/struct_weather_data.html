Detailed Description

Holds the weather data returned by a successful WeatherAction::execute() call.

Populated by WeatherAction::parseResponse() and retrievable via WeatherAction::getResult(). Temperature is provided in both Celsius and Fahrenheit for convenience; all other measurements use SI-adjacent units as noted per field.
