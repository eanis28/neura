Detailed Description

Manages microphone audio input using PortAudio.

This class wraps the lifecycle of a PortAudio input stream. It is responsible for initializing the selected microphone, starting the input stream, and stopping and cleaning up audio resources when finished.

bool AudioManager::init ( int micIndex)

Initializes and starts the PortAudio input stream.

Initializes and starts the PortAudio microphone input stream.

Opens the microphone stream for the given input device index and begins capturing audio samples.

Parameters
micIndexThe index of the microphone input device to use.
Returns
true if initialization succeeded, false if no valid input device was available or the stream could not be opened.

This function initializes PortAudio, selects either the requested microphone device or the default input device, configures the stream parameters, opens the input stream, and starts audio capture.

Parameters
micIndexThe index of the microphone device to use. If -1, the default input device is used.
Returns
true if the input stream was started successfully, false otherwise.
