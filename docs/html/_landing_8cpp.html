◆ loadLandingFont()

bool loadLandingFont ( sf::Font & font)
static

Attempts to load a system font with platform-specific fallbacks.

Tries multiple font paths in order of preference for each platform: macOS uses Avenir, Arial Unicode, or Arial; Windows uses Segoe UI, Arial, or Calibri; Linux uses DejaVu Sans or Liberation Sans.

Parameters
fontFont object to load the system font into
Returns
true if any font was successfully loaded, false if all attempts failed

◆ runLandingPage()

bool runLandingPage ( )

Displays the application landing page with navigation options.

Creates and runs a modal window showing the Neura landing screen with buttons for Start, Tutorial, and Settings. The window is centered on screen at half the desktop resolution. User can navigate to different parts of the application or close to exit.

Returns
true if user clicked Start or Tutorial (proceed to main app), false if user closed the window or pressed Escape (exit app)
