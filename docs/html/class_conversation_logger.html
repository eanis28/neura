Detailed Description

Appends structured JSON log entries for every command/response cycle.

Opens (or creates) a JSON file at construction and writes each entry immediately via log(). The destructor closes the JSON array correctly so the file is always well-formed, even after an unclean exit during normal operation (entries already flushed remain valid).

Meridith Shang

Closes the JSON array and flushes the file to disk.

Writes the closing ] bracket to ensure the file is a valid JSON array. Entries written before an unexpected termination (e.g. a crash after construction) remain readable up to the last successfully flushed entry.
